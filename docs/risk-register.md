# Architectural risk register

Risks identified before feature work, how the architecture resolves each one, and how the
resolution is verified. **Status** is either *Resolved (P0)* (mechanism built and tested in
Phase 0) or *Designed (Pn)* (mechanism fixed here, implemented and tested in phase *n*).
